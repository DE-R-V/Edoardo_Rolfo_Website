# Sito personale

Starter per un sito web con React, TypeScript e Vite.

## Avvio

```sh
npm install
npm run dev
```

## Comandi

- `npm run dev`: avvia il server di sviluppo con aggiornamento automatico.
- `npm run build`: crea la versione di produzione in `dist/`.
- `npm run preview`: serve localmente la build di produzione.
- `npm run lint`: controlla il codice con ESLint.
